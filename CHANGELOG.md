# Changelog

## [Unreleased]

### Added

- Homepage settings access and an editing mode for rearranging or hiding puzzle sections and trainers.
- An unread indicator on the homepage edit button when new trainers are available.
- Saved trainer search queries with synced per-trainer defaults, plus a built-in "No filter" option.

### Changed

- Algset bulk actions now operate on visible results while a trainer search is active.
- Trainer case groups can use a compact row-wrapped layout from the Styling settings.
